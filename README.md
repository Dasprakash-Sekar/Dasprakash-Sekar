### 🚀 About Me

Frontend Engineer with **3+ years** of experience designing, building, and maintaining scalable, responsive web applications with **React.js** and **JavaScript (ES6+)**. I specialize in **reusable UI components**, **RESTful API integration**, and **predictable state management with Redux**, turning product requirements into fast, maintainable interfaces.

- 🏢 **Now:** Frontend Engineer at **LUCID IT Solutions**, building **10+ enterprise web apps** for hospitality: POS, contactless ordering, self-service kiosks, and CRM.
- 🧩 **What I do best:** component-driven UI architecture, Redux Toolkit & TanStack Query data flows, and performance tuning with Vite code-splitting and smart caching.
- 🛠️ **Full-stack depth:** Node.js, Express & TypeScript APIs, PostgreSQL with Prisma ORM, and AWS (EC2, S3, CloudFront) deployments behind Nginx, PM2, and GitHub Actions CI/CD.
- 🎓 **Education:** MCA, Alagappa University &middot; B.Sc. IT, Hindusthan College of Arts & Science.
- 📫 **Open to** Frontend and Full-Stack engineering roles. Reach me at **das25kkdi@gmail.com**.
